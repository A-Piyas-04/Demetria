# Kemin Industries — Reference Analysis

**URL analyzed:** https://www.kemin.com/in/en/home  
**Scope:** Homepage + accessible section content (South Asia locale)  
**Method:** Live browser snapshot + content fetch (cookie consent blocked initial view)

---

## Observed facts

### Homepage structure

1. **Utility / region bar** — Region selector (“South Asia”), language (“English”)
2. **Primary nav** — PRODUCTS, SERVICES, logo, hamburger / utility menu
3. **Hero** — Full-bleed lab photography (scientists in lab coats); CTA “Explore Ingredient Solutions”
4. **Market expertise grid** — “Expertise for Every Market” with industry cards:
   - Animal Nutrition & Health
   - Animal Vaccines
   - Aquaculture
   - Food Technologies
   - Pet Food & Rendering
   - Textile Enzymes
5. **Science / brand story** — Curiosity + science narrative
6. **Credibility metrics strip** — manufacturing facilities, countries operated, customer countries, specialty ingredients count
7. **Corporate footer** (standard enterprise links)

### Navigation model

- Broad enterprise mega-nav by business division
- Strong product/services split
- Heavy internationalization (region + language)

### Visual design (observed)

| Token | Observation |
|-------|-------------|
| Brand red | Strong accent on logo and links (~corporate red) |
| Neutrals | Black / white / charcoal UI chrome |
| Imagery | Premium photography — lab, science, industrial credibility |
| Typography | Clean corporate sans-serif; high hierarchy contrast in hero |
| Buttons | Solid dark primary CTAs; outlined secondary |
| Layout | Spacious section rhythm; large hero plane |

### Strengths to borrow

- Premium full-bleed hero with science imagery
- Clear market/solution category cards
- Metric strip for corporate credibility (structure only — not their numbers)
- Restrained, polished corporate presentation
- Strong typography hierarchy

### Weaknesses / exclusions

- Excessively complex enterprise navigation
- Unrelated industry divisions (textiles, human food) for our single-brand animal nutrition site
- Region/language chrome unnecessary for this project
- Cookie / consent UX is heavy (not relevant to our static marketing site)

---

## Design recommendations (interpretation)

Use Kemin as the **visual foundation**: photography-led hero, calm corporate spacing, science-forward storytelling. Do **not** copy brand red, logo, or metric claims.
